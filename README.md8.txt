Simple Data Filtering

Description

This project demonstrates how to filter student records using Python conditions.

Objective

To understand how conditional statements can filter structured data based on marks, age, and department.

Tools Used

- Python
- Jupyter Notebook

Features

- Stores student records using a list of dictionaries.
- Filters students scoring above 80 marks.
- Filters students belonging to the MCA department.
- Filters students aged 22 or above.

Concepts Used

- Python lists
- Dictionaries
- Conditional statements
- List comprehensions
- Loops

How to Run

1. Open Jupyter Notebook.
2. Create a new Python notebook.
3. Copy the Python code into a cell.
4. Run the cell using Shift + Enter.

Conclusion

This project demonstrates basic data filtering techniques using Python.
